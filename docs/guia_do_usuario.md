# Guia do Usuário - Sistema de Reserva de Hotéis

## 1. Introdução
Bem-vindo ao Sistema de Reserva de Hotéis. Este guia tem como objetivo orientar os usuários sobre como acessar, navegar e utilizar as principais funcionalidades da nossa plataforma de reservas online.

## 2. Acesso ao Sistema
Para acessar a aplicação, utilize o link oficial do projeto hospedado na internet:
[Link da Aplicação - Exemplo](https://hotel-reservation-system-devsamyra.vercel.app)

## 3. Funcionalidades Principais

### 3.1. Pesquisa de Hotéis e Quartos
1. Na página inicial (**Home**), utilize a barra de busca.
2. Informe o **Destino**, as datas de **Check-in** e **Check-out**, e o número de **Hóspedes**.
3. Clique no botão **"Buscar"**.
4. O sistema exibirá uma lista de hotéis disponíveis com fotos, preços e avaliações.

### 3.2. Realização de Reserva
1. Após escolher um hotel, clique no card correspondente para ver mais detalhes.
2. Selecione o tipo de quarto desejado.
3. Clique em **"Reservar Agora"**.

### 3.3. Checkout e Pagamento
1. Na tela de **Checkout**, preencha seus dados pessoais (Nome, E-mail, Telefone).
2. Escolha o método de pagamento: **Cartão de Crédito** ou **PIX**.
3. Se escolher Cartão de Crédito, insira os dados solicitados de forma segura.
4. Revise o resumo da reserva no lado direito da tela.
5. Clique em **"Confirmar Reserva"**.
6. Você receberá um e-mail de confirmação com os detalhes da sua estadia.

## 4. Suporte e Contato
Em caso de dúvidas ou problemas técnicos, entre em contato com a nossa equipe de suporte através do e-mail: `suporte@hotelreserva.com.br`.
